# robot_bellows — 현역 로봇 플랫폼

`robot_bellows.usda` 하나가 전부다. 조립 코드가 없다 — **완성된 아티큘레이션을
reference 로 얹어 쓴다.** son 1세대처럼 스크립트가 링크를 짓지 않는다.

| 항목 | 값 |
|---|---|

| 장축 | **로컬 -Z** (son 은 X 였다. 축 규약이 다르다) |
| 바퀴 | **12** (레그당 2), r=10mm / 폭 4mm, 최대 토크 **14 mN·m** |
| 서스펜션 | **프리즈매틱 피스톤 6** — 스트로크 0~10mm, 강성 3000 N/m, 감쇠 20, target 0.02(상한 밖) → maxForce **9N 이 곧 예압** |
| 중앙부 | **벨로우즈 4관절** — 축이 X-Y-X-Y 로 교대, 각 **±27.5°** (평면당 ±55°), 강성 4.0 N·m/rad |

## 🚨 이 로봇을 쓸 때의 함정 (전부 실기 실측)

1. **물리 스텝 1/240 이 필수다.** 1/60 이면 피스톤이 한 스텝에 50mm 를 움직여
   (종단속도 3 m/s) 휠에서 관벽까지 남은 6.75mm 를 뛰어넘고 파고들어 **NaN 으로
   발산**한다. 배관을 빼면 부딪힐 게 없어 멀쩡한 것이 이 진단의 근거다.
2. **배치를 부모 Xform 에 걸면 안 된다.** reference 로 얹고 상위 Xform 에 변환을
   주면 `world.reset()` 직후 전 링크에 `Invalid PhysX transform` 이 뜨고 발산한다.
   son 이 적어 둔 *"articulation root 에 변환 op 금지"* 가 **부모 Xform 에도 적용**
   된다. → 각 링크의 로컬 변환에 굽는다(`GetLocalTransformation() * PLACE`).
   조인트의 `localPos/localRot` 은 바디 기준이라 불변이므로 안전하다.
3. **휠 충돌체를 실린더로 바꾸지 말 것.** son 라인의 확정 원인이 hull 이었기에
   똑같이 바꿨더니 주행 2.5mm 로 죽었다 — 휠 중심 반경이 45.8mm 까지 벽을 파고들고
   바퀴 편차 7,179° 로 헛돌았다. 이 조합(12륜·마찰 0.9 배관·LR)에서는 원본이 맞다.
4. **안착 중 뒤로 밀린다.** 피스톤 6개가 동시에 9N 으로 벽을 밀며 자세를 잡는
   과도 구간에서 **44mm**(무부하) ~ **74mm**(토치 63g 부착) 후퇴한다. 관 입구
   가까이에서 시작하면 후방이 관 밖으로 빠져 휠 6개가 자유공간에 뜨고 관 끝면에
   걸린다. 증상은 "견인력 부족" 처럼 보이지만 **배치 문제**다.
   → 안착 로그의 `휠 중심 반경`·`밀착 n/12`·`seg0_body x` 를 먼저 볼 것
     (정상: 반경 39.1~40.0mm, 밀착 12/12).
5. **USD 카메라는 자기 로컬 -Z 를 본다.** 이 로봇의 전방도 로컬 -Z 라 전방
   카메라는 **회전이 필요 없고**(항등) 후방만 Y축 180° 다. son `camera/rig.py` 의
   "시선은 +X" 는 son 축 규약에서 나온 말이라 그대로 옮기면 틀린다.
   그리고 카메라 프림은 링크의 자식이므로 **좌표가 링크 로컬**이다 — 로봇 루트
   기준 오프셋을 더하면 본체에 파묻힌다.

## 아직 없는 것

- ROS 발행 — `robot/state_bridge.py` 는 son 1세대 관절 이름(`joint_wheel_*`,
  `joint_arm_*`, `joint_waist`)을 쓴다. 이 로봇은 `seg0_wheel_0_0`,
  `seg0_piston_0`, `bellows_0` 이라 **그대로는 안 붙는다.** 이름 대응 필요.
- 자세·치수 시험 — son 의 `test_code/` 는 1세대 조립을 검사한다. 이 로봇용
  대조 시험은 없다.
