1. 프로젝트 정의
1.1 해결하려는 문제
가정 배관에서 누수가 발생했을 때, 원인 규명 전까지 수리가 불가능하여 피해가 지속되는 문제를 해결한다. 로봇이 배관 내부를 자율 점검하여 결함의 종류·위치·크기를 객관적으로 기록하고, 로봇이 수리 가능한 범위는 즉시 시공하며, 불가능한 범위는 관리자에게 보고한다.
1.2 디지털 트윈으로 검증하는 이유
실제 배관 진입 시험은 로봇 파손·배관 손상·회수 실패 위험이 있다.
결함 시나리오(크랙·구멍·단절)를 반복 재현하려면 실물로는 불가능하다.
곡관 통과 성공률, 정렬 정밀도 등은 정답을 알아야 정량 측정이 가능하며, 시뮬레이션에서만 정답을 확보할 수 있다.
1.3 프로젝트 성격
학생 프로젝트이며 상용화 목적이 아니다. 평가 대상은 물리 엔진 이해도와 ROS 활용도이므로, 실물 제작 가능성보다 시뮬레이션상의 물리적 타당성을 우선한다.

별도 거리 센서를 두지 않는 이유 : 카메라 Depth가 거리 측정을 겸한다. 급정지 판단용으로는 화면 중앙 영역의 평균 깊이만 사용하면 연산 부담 없이 단일 빔 센서와 동등한 값을 얻는다.
상용 depth 카메라를 쓰지 않는 이유 : Intel RealSense D455의 최소 측정 거리는 52cm로 관벽 거리 25mm의 20배이며, 본체 치수 124 x 25 x 29mm도 세그먼트 62mm 내부에 수용되지 않는다. Isaac Sim이 제공하는 다른 depth 카메라 자산(RealSense D555, Orbbec Gemini 2·335·Femto Mega, Leopard Imaging Owl, Sensing SG2) 역시 자율주행·서비스 로봇용이라 동일한 제약을 갖는다. 이 스케일에 대응하는 상용 자산은 존재하지 않는다.
보어스코프를 택한 근거 : 실제 배관 점검 장비는 스테레오 depth 카메라가 아니라 광각 보어스코프를 사용한다. 화각이 넓을수록 원통 관벽을 많이 확보하므로 원형도 판정과 축 오프셋 측정 양쪽에 유리하다.
카메라 사양 : 어안 투영 수평 화각 140도, 해상도 1280 x 720, 발행 주기 10Hz, 측정 범위 5~5,000mm. 깊이는 카메라 원점 기준 실제 거리를 사용한다(광축 투영 거리가 아니다). RGB는 압축, Depth는 무압축 32FC1로 전송한다.
시뮬레이션 구현 : 어안 Camera prim에 distance_to_camera 어노테이터를 적용한다. 광선 추적으로 깊이를 산출하므로 최소 측정 거리 제약이 없으며 25mm 근접 벽면도 측정된다. 다만 실물 센서보다 낙관적인 값이므로 실기 성능과 동일하지 않다.
확인 필요 : 시뮬레이터가 빈 공간의 깊이를 0 / inf / NaN / 최대거리 중 무엇으로 반환하는지 Day 2~3에 확인한다. 이 확인 없이 구현하면 관 단절 판정이 작동하지 않는다. 또한 near clip을 5mm로 둔 상태에서 관벽 25mm가 유효하게 측정되는지 함께 확인한다.

3.2 곡관 통과 기하

L_max = 2 × √( (R + D/2)² − (R − D/2 + d)² )

예압 9N의 근거는 정상 주행이 아니라 곡관 통과 조건에 있다.
4. 임무 시나리오
4.1 투입 방식
순차 투입. 정찰기가 임무를 완료하고 복귀한 후에 수리기를 투입한다.
근거 : 관이 완전히 단절되어 정찰기가 더 진행할 수 없는 상황에서 뒤에 수리기가 따라오고 있으면, 배관 내에서는 회전도 추월도 불가능하므로 두 로봇이 모두 갇힌다. 회수 실패는 곧 배관 폐쇄를 의미한다. 순차 투입은 동시 운용이 불가능해서가 아니라 회수 안전성을 위한 설계 판단이다.
부수 효과 : 두 로봇 간 충돌 회피, 간격 조율, 대기 위치 결정이 모두 불필요해진다. 또한 정찰 결과로 용접봉 총 소요량을 사전 계산하여 관리자가 필요한 만큼 장착할 수 있다.
4.2 정찰기 임무 절차
1) 투입 — 사각 거름망 한 변에 후방 세그먼트 2륜을 걸치고 반대편에 1륜이 오도록 배치
2) 전진 탐사 — 전방 카메라로 촬영하며 전진, 결함 후보 발견 시 정지하여 정밀 촬영 및 치수 실측
3) 종료 판정 — 30m 도달, 관 단절, 통행 불가 중 하나
4) 후진 복귀 — 후방 카메라로 2차 촬영을 수행하며 진입점으로 복귀
5) 보고 — 결함 목록, 위치, 치수, 용접봉 총 소요량 제출
4.3 수리기 임무 절차
1) 용접봉 장착 — 정찰 결과 기반 산출량을 관리자가 장착
2) 투입 — 정찰기와 동일 방식
3) 목표 이동 — 정찰기 기록의 거리·시계 방향으로 이동
4) 재확인 — 목표 지점에서 자체 카메라로 결함 재검출, 최종 정렬
5) 시공 — 토치 정렬 후 용접
6) 검증 — 냉각 대기 후 재촬영
7) 다음 목표 또는 복귀 — 용접봉 소진 시 복귀 및 관리자 알림
8) 복귀 중 재확인 — 후방 카메라로 수리 지점 재확인 및 미탐지 결함 탐색

5. 위치 추정
5.1 롤 기준
중력 기준 절대 롤을 사용한다. IMU 가속도계로 중력 방향을 읽어 현재 아래쪽이 어디인지를 항상 파악한다. 로봇이 어떻게 투입되었든 중력은 변하지 않으므로, 정찰기와 수리기의 투입 자세가 달라도 결함 위치 기록이 동일한 기준을 공유한다.
기계적 정렬 병용 : 사각 거름망 한 변에 후방 세그먼트 2륜을 걸쳐 초기 롤 편차를 ±30°에서 ±10° 이내로 줄인다. 다만 로봇이 원형 관 내부로 진입하면 6륜이 재정렬되며 롤이 다시 변하므로, IMU 절대 롤이 최종 기준이 된다. 기준 세그먼트는 후방으로 통일한다.

5.3 도면 기반 위상 매칭
배관 도면에서 곡관과 분기점을 노드로 하는 그래프를 구성하고, 로봇이 곡관을 통과할 때마다 노드를 진행시킨다.
직진 구간: 바퀴 엔코더로 거리 적산 (슬립 오차 누적)
곡관 통과: 누적 오차를 도면상 해당 노드 위치로 리셋
이 구조로 오차가 곡관 간 구간 내로 제한된다. 두 로봇의 오도메트리 오차는 서로 다르므로, 정찰기의 거리 값은 개략 위치로만 사용하고 수리기가 목표 지점 근처에서 자체 카메라로 결함을 재검출하여 최종 정렬한다.

6.2 판정 기준
수리 가능 여부는 용접봉 잔량 단일 기준으로 판정한다. 결함 크기 자체에 대한 제한은 두지 않는다.

→ 수리 불가, 관리자 보고
elif 잔량 − 소요량 &gt;= 예비 10mm:
→ 수리 실행, 잔량 차감
else:
→ 위치 기록 후 보고, 정찰 계속
단일 기준으로 통일한 근거 : 로봇이 수리하지 못하는 이유는 결함이 너무 커서가 아니라 자원이 부족해서이다. 용접봉을 더 장착하면 해결된다. 파이프 단절만 자원과 무관하게 불가능하다.

7.2 시뮬레이션 구현
중요 : 용접 이벤트만으로 결함 프림을 무조건 제거하면 검증이 항상 통과하여 성공률이 100%가 된다. 검증이 작동하지 않는다는 뜻이므로 조건을 넣어야 한다.

결함 프림 숨김 + 비드를 결함 위치에 표시
→ 검증 촬영 시 미검출 → 성공
else:
결함 프림 유지 + 비드를 어긋난 위치에 표시
→ 검증 촬영 시 여전히 검출 → 실패

허용치: Day 5~6에 20회 이상 실측하여 오차 분포를 확인한 후 결정한다.
냉각 대기: 결함 크기에 비례하여 5~15초 대기 후 검증 촬영을 수행한다.

비드 프림 형상 : 결함을 메운 형태로 만든다. 크랙은 홈을 채운 볼록한 띠, 구멍은 개구부를 덮은 원반이다. 관 내벽보다 약간 돌출시키면 Depth로도 메워짐이 확인되고, 열영향부 변색을 흉내 낸 재질을 입히면 수리 지점이 영상에 남는다.
이 방식의 핵심 : 검출기를 속여 안 보이게 만드는 것이 아니라, 형상 자체를 바꾸어 결함이 아니게 만드는 것이다. 그래야 RGB와 Depth 양쪽에서 일관되게 검증이 성립한다.
확장 아이디어 (챌린지 항목) : 비드를 여러 조각으로 분할해 두고 정렬 오차에 따라 겹치는 조각만 표시하면 &quot;절반만 메워짐&quot; 같은 중간 상태를 표현할 수 있다. 정렬 정밀도 지표가 풍부해지나, 8일 일정에서는 성공/실패 이분법으로 충분하다.
8. 이상 상황 대응
8.1 관 단절 판정
관 내부는 항상 원형이므로 원형이 깨지는 것이 이상 신호이다. 그레이스케일 변환 후 이진화하여 윤곽선을 찾고 원형도를 계산한다. 완전한 원은 1.0이며 찌그러질수록 작아진다.
원형도 = 4π × 면적 / 둘레²
신호 1 — 원형도 저하 (카메라). 임계값은 Day 3~4에 정상 주행 데이터 수집 후 결정한다.
신호 2 — 전방 Depth 급감. 관절 각도 변화가 없으면 곡관이 아니라 막힘이다.
신호 3 — 서스펜션 압축 이상. 관 단면이 좁아지면 암이 정상 범위를 벗어난다.

12. Isaac Sim 파라미터
12.1 서스펜션 조인트 드라이브
스프링을 형상으로 모델링하지 않고 조인트 드라이브의 강성으로 구현한다. 조인트 드라이브는 내부적으로 스프링-댐퍼 식을 암시적(implicit)으로 처리하므로, 명시적 외력 방식보다 수치적으로 안정하다.
τ = stiffness ( target − q ) − damping q̇
--- 스윙암 (Revolute Joint) ---
axis              : 접선 방향
limits            : 33.4° ~ 58.2°
drive mode        : position
targetPosition    : 60°            (상한 밖)
stiffness         : 0.74  N·m/rad
damping           : 0.009 N·m·s/rad
maxForce          : 0.257 N·m      (= 예압 9N)
--- 직동식 (Prismatic Joint), 1차 검증용 ---
limits            : ±6 mm
stiffness         : 900 N/m
damping           : 30  N·s/m
maxForce          : 9   N
목표 각도를 조인트 상한 밖에 두고 maxForce로 제한하면 위치와 무관하게 일정 예압이 발생한다. 실제 정하중 스프링과 동일한 거동이다.
12.2 필수 물리 설정
contactOffset       : 0.0005 m
restOffset          : 0
물리 스텝            : 1/240 이상 (불안정 시 1/500)
솔버 반복 (position) : 32
솔버 반복 (velocity) : 4
주의 : Isaac Sim 기본 contactOffset은 0.02m(20mm)이다. 휠 반경 10mm 스케일에서는 접촉이 실제 표면보다 훨씬 앞에서 발생하여 로봇이 공중에 뜬 것처럼 거동한다. 이 설정 누락이 가장 빈번한 실패 원인이다.

14. 설계 한계
발표 시 명시할 항목이다.
한계
내용
분기관 경로 선택 불가
관절이 수동이므로 T자 분기에서 진행 방향을 능동 선택할 수 없다. 단일 경로 배관을 대상으로 하며, 분기 구간은 별도 진입점 사용을 전제한다.
순차 투입 시간 비용
동시 운용 시 임무 시간을 단축할 수 있으나, 관 단절 시 회수 실패 위험으로 순차 투입을 선택했다. 안전성과 효율의 트레이드오프이다.
만관 용접 불가
수중 아크 용접이 성립하지 않아 수리 단계에서 배수를 전제한다. 배수 자체는 로봇이 수행하지 않는다.
파이프 단절 수리 불가
구조적 손상이므로 로봇이 대응할 수 없다. 굴착 교체 판단은 사람이 내려야 한다.
원주 방향 대형 결함
토치 접근 자세 유지 범위는 약 ±45°(원주 길이 78mm)이다. 초과 시 분할 시공 또는 보고 전환한다.
센서 적용 한계
상용 depth 카메라는 최소 측정 거리가 관벽 거리 25mm를 크게 초과하여(D455 기준 52cm) 적용할 수 없다. 광각 보어스코프를 가정하고 시뮬레이션에서는 광선 추적 기반 깊이로 대체한다. 광선 추적 깊이는 최소 측정 거리 제약이 없어 실물 센서보다 낙관적이므로, 시뮬레이션 결과가 곧 실기 성능을 보장하지 않는다. 실기 적용 시 근접 측정이 가능한 센서로의 전환이 필요하다.

초기 기획을 물리적 타당성 기준으로 검토하면서 드러난 문제들이다. 대부분은 실제로 계산해 보기 전까지 드러나지 않았다.
16.1 곡관 통과 기하 — 설계 전체를 되돌린 지점
직선 배관만 상정하고 로봇 길이를 정했으나, 곡관에서는 강체 길이가 통과 가능 여부를 직접 결정한다. 로봇 섀시는 직선인데 배관 중심선은 원호이므로 섀시 축은 원호에 대한 현(弦)이 되고, 그 편차를 서스펜션이 흡수해야 한다.

설계 스트로크 ±6mm 기준으로 일체형 150mm는 SR·LR 모두 통과하지 못한다. 본체를 2등분한 것은 형상 취향이 아니라 이 계산의 결과이며, 강체 단위가 62mm로 줄면서 필요 스트로크가 6배 이상 완화되었다.
같은 이유로 초기 기획의 DN50 샤워 배수구 직접 진입도 성립하지 않는다. 트랩 곡률이 SR급이라 통과 가능한 최대 강체 길이가 74.8mm에 불과하다.
16.2 수리 공법과 유체 조건의 충돌
만관을 전제로 유체력을 계산해 놓고 용접을 수리 방식으로 정했으나, 수중 아크 용접은 성립하지 않는다. 정찰은 만관, 수리는 배수 후로 분리했다. 실제 배관 보수 절차와도 일치하며, 정찰기의 유체력 시뮬레이션은 그대로 유지된다.
16.3 검증 로직의 자기충족 문제
&quot;용접 후 결함이 사라지면 성공&quot;으로 정의했으나, 시뮬레이션에서 용접 이벤트만으로 결함을 제거하면 성공률이 항상 100%가 된다. 검증이 작동하지 않는다는 뜻이다. 정렬 오차 조건을 추가하여 실패가 실제로 발생하도록 했다. 7.2절과 7.3절 참조.

16.5 발표 시 강조할 항목
위 항목 중 곡관 통과 기하(16.1), 수리 공법과 유체 조건(16.2), 검증 로직(16.3) 세 가지를 우선 제시한다. 모두 계산을 통해 초기 판단이 뒤집힌 사례이므로 공학적 검토 과정을 보여주기에 적합하며, 특히 16.3은 평가 항목의 &quot;실패 원인과 한계를 분석했다&quot;에 직접 대응한다.
